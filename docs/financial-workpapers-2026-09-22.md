# 同行参考与现金流计算底稿

## 实施边界

借鉴 financial-analysis 的结构化比较和财务建模留痕思路；没有安装、运行或复制其 Python 模板，不引入 DCF、LBO 或目标价模型。

- 公司信息页新增独立加载的「同行候选与估值参考」。不阻塞原股价数据，页面可见时最多每 5 分钟刷新一次 HTTP 数据。
- 行业归属与完整成分复用现有东方财富接口、HTTP 降级和 D1 缓存；一次腾讯批量请求取得候选行情。PE 使用现有适配器的 TTM 字段，不把动态 PE 当 TTM。
- 先核验行业分类，再从完整成分按市值比例距离选择最多 8 家，不按涨幅选股。来源返回多个行业时采用首项并披露全部归属，不声称是最细分类。行业相同仅产生候选，不证明业务可比。
- 仅统计同源、同日、相差不超过 5 分钟的有效样本。目标公司不参与样本分位计算；不足 4 家不输出分位。ST/退市标识、停牌、过期、缺值及非正估值有明确排除原因。PB 财报分母期间未核验，展示为来源字段参考，不宣称严格同财报期。
- 分位使用 R7 线性插值；目标位置使用中间秩。保留原值、抽样市值、样本代码、时间、来源及排除项。该统计不是全行业排名或内在价值。
- 报告同行分析新增入选依据与证据期间；只接受有业务比较证据的具名公司，资料不足留空。旧报告无新增字段仍可打开。
- 现金流新增 `经营活动产生的现金流量净额 − 购建固定资产、无形资产和其他长期资产支付的现金`。仅接收同期间、CNY、元、合并、累计及可追溯来源数据。支出同义科目冲突会阻断计算，缺失不填零，负支出不机械取绝对值。
- 结果命名「简化现金结余」，不是 FCFF/FCFE 或可分配现金；不重复扣减营运资本，不把该科目当全部资本投入，也不机械用于金融行业估值。
- 完整底稿及同行行情冻结在报告和研究证据中，复用原报告存储和打印展开机制。打开已存报告不刷新、不重新调用 AI。
- 不新增模型阶段、Key、依赖或数据库迁移；沿用 BYOK、登录、权限、并发与预算约束。写作只接收有界摘要，资料正文预算会扣除新增质量上下文长度。

## 入口

- `lib/a-stock-peers.ts`：有界 HTTP 采集和共享快照。
- `lib/company-peers.ts`：抽样、过滤、分位及写作摘要。
- `lib/research-quality.ts`：现金流科目和可复算底稿。
- `components/company-peers.tsx`：实时与报告冻结快照共用展示。
- `lib/company-research-pipeline.ts`：沿用 collect/business/finance 并保存底稿来源。
