# 深度公司研究标准与富祥股份验收集

参考用户提供的 15 页《富祥股份深度分析报告》（2026-07-23，数据截至 2026-07-22）。它只用于研究方法与验收，不能作为新报告的事实数据库。

## 完整分析思路

确认对象与时点 → 拆开收入和利润 → 逐业务追踪量价成本/产能客户 → 行业供需 → 竞争壁垒 → 三表兑现质量 → 治理资本配置 → 估值隐含条件 → 情景与催化 → 风险证伪及结论。

| 重要板块 | 样本位置 | 研究标准 |
|---|---|---|
| 核心摘要与边界 | 1–2 页 | 确认证券、上市地、币种；报告日、行情日、财务期间分开；点明利润主线、变化和主要不确定性。 |
| 公司沿革与战略定位 | 2–4 页 | 主业和转型路径；技术/产线复用还是跨界，不复述概念标签。 |

## 样本不是事实金标准

- 样本综合分标题写 7.15，列示公式算得 7.075；不能复制其分数或算术错误。
- 存在半年报对应 H2 等期间表述问题，需重新核验。
- 推算销量、市场份额、预测利润和场景概率不等于已实现事实。
- 不迁移买入区间、止损、仓位、收益目标，遵守项目“仅分析、非投资建议”的边界。

## 实现边界

HTTP 先收集多期财报和公告正文，结构化摘录复用现有 D1；行情单独刷新。先识别缺口、有限联网补证，再从资料包写作。深度报告预算与市场 chat 独立，不再限制全文 1800 字，不反复完整重生成。不加数据 Key、不新增后台 AI 定时器。检查按条目进行，不能让一个格式错误抹掉整篇有效分析。旧报告继续直接读取。

## 冻结的富祥股份验证集

以当前时点取数，对比研究维度而不是复现 7 月价格。不得把样本公司数字注入生成提示词。各项记录通过/部分/未通过，不以总分掩盖关键错误：

1. 对象/上市地正确，行情有源和时间，失联明确缺失。
2. 医药、锂电添加剂、合成生物/蛋白的定位和阶段被核验。
3. 分部收入/占比/毛利率有期间与正文依据，缺失留空。
4. VC/FEC 等关键产品量价成本传导，不用技术指标。
5. 实际竞争对象、竞合关系、壁垒和反证。
6. 多期财务、利润现金匹配、债务/资本开支风险。
7. 联营/CDMO、协同和商业化阶段，不能生搬样本。
8. 估值口径、负利润/预测区别，无伪造历史分位。
9. 治理、募投、关联交易和合规按实际检索说明。
10. 三种有公司具体变量的经营情景与证伪条件。
11. 有来源的催化时间线，计划不作已完成。
12. 核心结论、首要风险和证伪条件与正文一致。
13. 抽查关键数字和原文；展示链接属本轮取得来源；不伪造客户/份额/认证。
14. 无交易指令、无依据预测、目标价和密钥泄漏。
15. 记录实际请求、Token、联网次数、耗时、失败与剩余缺口。
