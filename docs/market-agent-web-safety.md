# 市场 Agent：受限联网与金融范围防护

## 调用流程

登录／同源 JSON／BYOK／模型权限 → 本地输入检查 → 分流：

- 完整问句匹配的常见金融定义：固定解释，零模型调用。
- 汇率询价（V3.10.5）：移除 RBA／ECB 汇率直连、XML 解析与进程汇率缓存；统一执行无工具分类 → 受限联网回答 → 独立复核。完整问句识别仅用来规范币种对和强制检索，不能绕过范围检查；单一外币简写默认兑人民币并提示假设。必须有实际搜索及安全来源，资料不足时说明缺口，不用模型记忆补数。原有官方／媒体搜索域名范围不变，并非禁止检索央行的公开网页。报价需标明日期／时间、方向与口径，不冒充实时成交价。
- 其他纯概念问题：无工具范围分类与简短解释 → 独立无工具输出复核，两次模型调用。
- 最新事实／行业动态：无工具分类 → 受限联网回答 → 独立无工具复核，三次模型调用。
- 多模块深度分析：通过范围检查后推荐用户手动打开 AI自定义研报，不自动生成或付费重跑。

只改变 `/api/chat`，不改变深度研究 collect/write、默认模型、用户模型偏好或原有账单来源。无新增 Key、后台任务、定时模型调用或新依赖。

### 输入边界

- 保留登录、暂停、允许模型、同源请求与 16 KB 请求上限。问题最多 800 字，非字符串拒绝。
- 规范化不可见字符，拦截明显凭据、个人标识、覆盖指令及异常编码。此启发式不是完整安全判定。
- 独立无工具分类器检查完整问题；纯非金融、金融与非金融混合、角色伪装、索取秘密等不放行。仅允许抽取后的公开金融问题进入联网阶段。
- 忽略客户端传来的 `context`、工具设置、域名等；不传页面 DOM、用户身份、私有报告或账户信息。历史按最多六条、每条最多800字、总计最多2400字裁剪，过滤显著隐私/注入/URL，仅供无工具分类器解析追问。历史角色与文字都不具指令权；只有再次验证的公开金融查询进入搜索阶段。含“当前页面”等不明确指代按整体市场处理，需要具体公司时应明确输入公司名／代码。

### 检索与不可信资料

- 使用 Responses API 正式 `web_search`，服务端固定 `filters.allowed_domains`。禁止降级为不支持域名过滤的 preview 或取消过滤重试。
- 时效性事实要求实际检索；纯金融概念可不搜索。原问题和历史改写后的公开问题都检查“最新／当前”等时效要求，简单汇率询价也强制检索，不能被分类器降级为仅模型记忆。
- 最多 1 次搜索工具调用、low 检索上下文、900 输出 Token；只有只读公开搜索，没有发信、交易、执行代码、文件、账户／数据库操作工具。
- 网站已有新闻／行业资料只读共享快照，不触发串行 HTTP 刷新；已过期的快照不加入上下文。摘要最多 6 条，可选快照最多等待800毫秒，慢缓存不再挡住后续检索。超时不取消底层已发出的只读 D1 操作，但不会等待其结果或增加模型请求。
- 允许域名并不等于可信内容。网页／公告／摘要／元数据始终只是事实候选，不能覆盖开发者指令；提示词明确拒绝资料中的工具、泄密、改任务及解码执行要求。
- 输入 Key 只在服务端 Authorization 头使用；沿用不跟随上游重定向、密钥脱敏、每阶段重新检查 BYOK 和模型权限。

### 输出边界

- 草稿先做运行时结构、长度与明显攻击检查，再由独立无工具审核调用检查所有正文与要点是否金融相关、切题且安全。
- 不流式展示未经审核的草稿；审核拒绝、结构不完整或审核请求失败均不返回草稿，也不自动重试。
- 最新问题没有实际搜索或可用安全来源时明确无法核实；联网搜索不等于交易所实时行情，不能声称每条结果都是实时数据。
- 链接仅取服务器 API 证据或 OpenAI 返回的搜索来源，不采用模型正文捏造的 href。校验 HTTP(S)、精确域名／子域边界、端口、凭据、异常编码、敏感／跳转参数等，去重最多 4 条。
- 外部标题不直接展示，来源标签使用经过校验的域名；正文移除 URL 和内部引用标记，前端沿用 React 纯文本输出（不渲染模型 HTML／图片），新窗链接不传 referrer。

## 成本、超时与审计

固定解释零模型请求；汇率与其他问答最多 3 个模型请求：`/api/chat:scope`（600 输出 Token，纯概念可在此生成简短解释）、`/api/chat`（900）、`/api/chat:output-check`（160）。概念快分支跳过中间写作调用，但保留独立复核。沿用用户允许且选定的聊天模型，搜索另行计费，不能把输出预算当总输入账单上限。汇率不再承诺零 Token 或直连接口的响应速度。

V3.10.4 修复聊天分支把所有阶段强制设为 low 推理的问题：无工具分类／复核和概念写作复用已有模型配置（GPT-5.4／mini 为 none），联网写作保留 low 以兼顾搜索质量。不更换模型、不增加输出额度或自动重试。`incomplete`／结构错误仍记录原始原因码并失败关闭；聊天界面改为“本次回答未完整生成”，不再误称“结构化报告”或要求切换 mini。截图本身不能确定哪一个阶段耗尽预算；后台按阶段的审计才是具体归因依据。

显著恶意输入零模型调用；一般非金融问题只有分类调用。各阶段的用户、模型、计费来源、Token 和搜索次数均记录在现有后台。没有自动重试或后台 Token 消耗。

总信号截止45秒（模型各阶段10／24／7秒），早于前端50秒取消；为身份、凭据和审计留出余量，但这些平台数据库操作的实际延迟仍可能影响总耗时。任何取消阻止后续模型阶段。单 Worker 实例内每用户仅一个在途请求；不是跨实例的分布式速率限制，不能宣称防住所有刷量，平台限额／预算告警仍有价值。拒绝分支记录非敏感原因码（scope_rejected/draft_invalid/output_rejected/sources_unavailable），不记录原问题或回答正文，便于区分格式失败与金融范围误判。

## 聊天历史和记忆

V3.10.3 使用按已登录账户ID隔离的 localStorage 历史；匿名状态不读取用户记录。所有已保存消息可滚动查看，初次显示最近20条，再每次加载20条。存储失败显式提醒，不静默截断旧记录；可手动清空。完整记录不是完整模型上下文，仅上述有界摘要窗口进入分类器。

记录在同一浏览器跨页面和刷新恢复，不是云端同步；清除浏览器站点数据或换设备不会保留。组件重挂不会中断同一文档内的在途请求。为了保留项目已验证的整页导航兼容性，本轮没有全面替换路由：刷新／整页跳转可能中断未完成请求，恢复时显示中断提示且不自动重发。已发送上游的请求即使浏览器中断也可能计费；仅保留已完成的结果，不承诺中断后找回未到达浏览器的回答。

## 验证与剩余风险

离线回归 `tests/market-agent-security.test.ts` 运行真实路由与 Responses 请求构造，模拟提供方结果验证域名工具配置、金融拒绝、恶意快照、输出拒绝、不安全 URL、伪造参数、权限、审计、锁、取消、历史隔离和快路径。`market-agent-fast.test.ts` 验证币种识别、方向和混合问句不匹配；汇率路由回归禁止访问央行接口，验证强制搜索、来源缺失拒绝和独立审核；`market-agent-chat-store.test.ts` 验证持久化、旧记录与账户隔离；`market-agent-ui-qa.mjs` 使用全网络拦截的离线浏览器验证历史查看、整页跳转、组件重挂、切换账户和手机布局。沿用 BYOK 与访问控制测试。模拟分类结果用于验证强制执行链，不能证明真实模型对所有语义攻击都能识别，也不代替真实模型耗时测量。

提示词注入没有绝对免疫保证；允许的网站也可能被入侵，分类与审核可能误判，公开来源也可能错误／过时。当前防护是减少暴露面、隔离敏感上下文、收紧工具权限、双向检查与失败关闭，而非声称百分之百安全。未来若需要更严格的交易／私有知识操作，必须另行设计授权、独立安全评估和分布式限流，不能复用此只读工具的授权。
