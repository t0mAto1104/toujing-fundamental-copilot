# 科创板证券搜索修复验收（2026-09-27）

## 原因与范围

- 真实东方财富 suggest 返回凯赛生物 `688065 / 1.688065`、敏芯股份 `688286 / 1.688286`，两者均为 `JYS=23`、`SecurityTypeName=科创板`。
- 修改前生产 `/api/listings` 对两家公司的名称和代码均返回 HTTP 200 空列表；行情名称搜索同样为空。共用 `toListing` 的允许类型漏掉科创板，本地以真实字段复现为 `null`。并非本次上游搜索接口不可达。
- 公司搜索不保存空结果；行情名称搜索会保存一小时快照，旧空列表或不完整列表可能延续到修复之后。

## 最小修复

- 共用证券类型白名单增加精确的“科创板”，保留现有沪市身份转换、交易所与代码校验，以及基金、指数、债券、期权等过滤。不硬编码公司例外。
- 行情名称搜索缓存升级为 `quote-search:v2`，绕过旧版错误结果，不删除数据库、不更改其他行情缓存。
- 不改 UI、数据供应商、模型、凭据或定时器；没有触发真实 AI 请求。

## 验证

- 新增 `tests/star-security-search.test.ts`：修改前两项测试失败，修改后通过。
- 覆盖两家公司名称、纯代码、SH 前缀、.SH 后缀在公司/行情两个 API 的结果；同时覆盖错误交易所、非股票过滤、旧空缓存失效和正常缓存复用。
- 全套离线测试 391 项通过，`tsc --noEmit` 和 `npm run build` 通过。
- 本地预览 `/api/listings` 与 `/api/quotes/search` 实测两家公司名称均返回 HTTP 200 和正确的沪市证券身份。
- 本轮未公开部署；线上生效需单独发布。
