# 行业研究与资金刷新

## 功能

- `/industry` 默认进入单行业研究；保留双行业比较，另设板块资金页签。
- 从数据源实际分类选择精确 BK 代码；领涨前 10 按全体成分股当日涨幅排序，不是推荐名单或基本面排名。不足 10 条不补造。
- 用户手动生成政策、行业、资金、财报、宏观五维研究。每项包括事实依据、传导机制、反证、验证指标；结论包括驱动、风险及可推翻判断的条件。
- 复用账户 BYOK、允许模型、研究模型偏好、权限校验和用量审计。每次研究最多一次模型请求、2 次联网工具调用、6000 输出 Token；115 秒总时限，不自动重试。
- 行情更新不自动调用 AI，不改写已生成结论。切换账户卸载旧结果并中止连接；切换行业清除旧结论。

## 刷新与时效

旧行业页面只在挂载时读取一次；接口可能先返回旧快照、后台更新，但页面不再检查，导致一直显示旧值。板块资金原有轮询和共享缓存均为五分钟，手动刷新仍可能直接命中缓存；缓存刚写入也不能证明源行情新鲜。

- 可见页签盘中每分钟检查，休市降为五分钟；恢复前台重新检查，离开/隐藏页签停止轮询。
- 行业研究使用有界等待刷新接口；18 秒未完成时可返回明确标旧的缓存，后台继续 HTTP 刷新。
- 行业快照与板块资金共享缓存改为一分钟；资金手动刷新可跳过缓存有效期，但保留 15 秒共享保护和失败冷却。
- `f124` 来源时间与 HTTP 获取时间分别展示。午休、收盘、周末不把上午旧快照重新视为新鲜。时间缺失、未来值和交易日历未核验均明确警告。
- 无时区新闻按北京时间解释，不误删当天最近八小时的新闻。

### 外部限制

本机公开 HTTP 读取时，东方财富 `push2`、`push2delay` 各一次请求均返回 502 HTML，没有行情 JSON。失败发生在解析之前；不能仅凭此区分源端与网络中间层。代码按设计显示旧快照/缺失提示，但本轮未确认实时行情源恢复。不得将自动刷新逻辑通过测试等同于源端恢复。

浏览器连接在用户中断后的重连被安全策略拦截，未绕过；中断前的离线交互验收完成，恢复后的代码验证通过。
