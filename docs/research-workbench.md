# 研究工作台：第 1～8 项实施说明

本轮复用现有 HTTP 数据链路、D1、身份验证和 OpenAI 调用封装。没有引入新的 API Key、后台服务或后台 AI 定时任务，也未复制 TradingAgents-CN 的应用源码。前端保持现有中文主题。

## 功能入口

| 项目 | 入口 | 本轮实现 |
| --- | --- | --- |
| 1. 任务中心 | 我的报告 → 研究任务与历史版本 | D1 任务状态、真实阶段、错误、已保存分段、手动续接和停止；完成报告由服务端先保存再返回 |
| 2. 数据健康 | 后台管理 → 研究运营与数据时效 | 被动记录取数成功/失败、耗时、缓存命中、来源数据日期及字段覆盖；无主动探活 |
| 3. 费用预算 | 任务详情、后台预算管理 | 每报告 Token/USD 预算、请求前原子预留、实际用量结算、未知用量保留预留；后台按报告归集费用 |
| 4. 财务口径 | 新生成报告的财务部分 | 显式货币、单位、合并范围及累计/时点口径；TTM 为上一年全年 + 本年累计 − 上年同期，保留原值与来源 |
| 5. 新闻证据 | 宏观资讯与研究取证 | 追踪参数清理、日期与内容去重、修订/相反观点保留、未来及无日期新闻过滤；公司资讯限定近 30 天 |
| 6. 报告版本 | 任务版本链接、报告元数据 | 独立任务快照、模型/框架/管线版本、证据时点和关键摘录导出；同证券两版本确定性比较，无额外 AI |
| 7. 自选研究 | 行情数据 → 标签、研究备注与筛选 | D1 用户隔离保存标签、备注和待验证事件；自选范围内按标签、正 PE TTM、正 PB、最低市值及新鲜度筛选 |
| 8. 有限批量 | 我的报告 → 新建单份/批量研究 | 用户确认预算后最多 3 家，逐家执行；每用户 1 个、全站 2 个有效研究租约；失败即停止，待启动最多 50 个 |

## 执行与成本边界

- 只有明确启动或手动续接才发起 AI 研究；保存待办、轮询任务、查看报告、对比版本、查看后台都不会发起 AI。
- 页面离开会取消客户端连接，不是离线后台队列。未运行的批量任务仍保留，可再次手动启动。
- 单次租约 10 分钟；超时失效。已保存分段的证据/写作检查点一小时内优先复用，过期后可能重新取证计费。新管线版本不能复用旧任务。
- 同一任务续接不重复扣每日研究次数；取消不代表已发出的请求没有收费。
- 初始每用户单报告上限为 80,000 Token / USD 2，管理员可以调整。批量表单从账户预算读取默认值，不修改原有默认模型。
- 预算是请求放行控制，不是供应商账单硬封顶。联网产生的上下文、失败后未返回用量、第三方计费变化均可能导致预估偏差；未知项不按零处理。费率复用既有 `ai-pricing.ts`，没有在本轮重新核价。
- 新任务完成结果独立保留，不自动覆盖。下方旧报告列表继续兼容；同公司旧浏览器副本不再优先覆盖已保存的服务端新结果。

## 数据真实性边界

- 缺失、口径不明或冲突的财务值明确标记，不能按零计算。TTM 不外推利润，不滚动相加资产负债表余额，不混用营业总收入与营业收入。
- TTM 仅基于本轮可取得报表；尚非历史披露时点数据库，不能用于声称无前视偏差的历史回测。
- 新闻去重在截断之前进行；同 URL 的修订内容、不同日期和相反观点不会被简单标题去重吞掉。
- 事件对订单、毛利或现金流的传导必须核验公司敞口；宏观消息本身不能证明某公司受益。
- 健康面板是最近真实访问的观测，不是实时在线保证。没有上游日期就标明未记录，抓取时间不能替代发布时间。诊断失败不阻断正常行情响应。
- 自选筛选不是全市场选股，不提供买卖建议；待验证事件只是用户记录，不会自动调用 AI 或发通知。
