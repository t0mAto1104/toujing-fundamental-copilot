# 账号笔记本

右上角原通知图标替换为笔记入口，首页与工作台共用同一个全站浮窗。每个登录账号一份持续编辑的富文本笔记；不调用 AI。

- 支持拖动、四边与四角共八个方向的缩放、最大化/还原、最小化；缩放时固定对侧边缘，到最小尺寸或屏幕边缘后停止变化。移动手柄支持方向键以及点击后的移动/大小按钮。
- 最小化条和缩小后的窗口都能移到屏幕右侧、底部，并在刷新后恢复位置；重新展开时会调整到整个窗口均可见的位置。
- 支持 12–32px 字号、加粗、斜体、文字颜色和高亮，原生撤销、中文输入及纯文本粘贴。导出 HTML（保留格式）或 TXT。
- 停止编辑 800ms 后按顺序自动保存到 D1。最小化立即触发保存，切换页面使用相同账号的云端内容并恢复浮窗状态。
- 本次打开后没有修改，或当前内容为空／只有空白时，关闭不弹提示。仅查看已保存笔记再关闭会保留账号内容；输入后撤销回本次打开时的内容，也可直接关闭。
- 本次打开后修改过且当前非空时，关闭仍会提示，即使自动保存已完成。可选择保存并关闭、导出并关闭、取消或“不保存，删除”；导出并关闭也保留账号副本。“不保存，删除”会清空账号笔记，包括已自动保存的内容。主动清空编辑区后直接关闭，也会保存当前空内容。
- 未确认上传的草稿临时保存在该标签页的账号专属 sessionStorage 中；它不是持久化主存储。保存成功或确认删除后移除草稿。冲突/保存失败仍保留可导出的内容。

## 数据与安全

`drizzle/0010_user_notebooks.sql` 创建 `user_notebooks`。`GET/PUT/DELETE /api/notebook` 以服务端认证身份隔离，写入要求同源 JSON、匹配的账号提示头和修订号；提示头不授予权限。修订号比较与写入在单条 SQL 内原子完成，冲突返回 409，不静默覆盖。删除清空内容但保留递增版本墓碑，阻止旧页面迟到的保存恢复已删除内容。

仅保存经过校验的文字和固定格式属性，不接受 HTML、脚本、图片或外部链接对象。输入上限 16,000 字符 / 500 个格式片段 / 60 KiB 请求体。HTML 导出对文字转义，并禁止脚本和外部资源。接口响应禁止缓存，日志不包含笔记正文。

## 验证

- `node --import ./tests/runtime.mjs --test tests/notebook.test.ts tests/notebook-client.test.ts`：认证、账号隔离、CSRF、格式/大小边界、并发版本、删除防复活、请求失败与跨页草稿恢复。
- `scripts/notebook-editor-smoke.mjs`：原生格式、选择、撤销、粘贴、新行、长度限制、组合输入事件、窄屏。
- `scripts/notebook-window-smoke.mjs`：StrictMode、八方向缩放与对侧固定、大幅拖动后的尺寸边界、最小化／小窗口贴右侧和底部及刷新恢复、展开可见性、页面跳转、账号切换、关闭条件、下载与移动屏幕。关闭测试覆盖仅查看已保存笔记、空白、撤销回原文、修改后已自动保存以及明确删除。两个浏览器脚本接受已安装的 Playwright 模块路径作为第一个参数，仅使用隔离测试页面；窗口测试模拟云端，不访问生产数据或 AI。
