# 公司研究方法

当前执行版本为 business-driver-evidence-v3，完整的 15 项标准及冻结验收条件见 [深度研究标准](research-standard-v2.md)。本文件保留通用原则摘要。

从用户提供的《富祥股份深度分析_report.pdf》（15 页）提炼通用研究方法；不上传、公开或逐次发送原 PDF，不把其数字和结论作为其他公司的证据。

## 保留的分析思路

1. 业务拆分：收入体量与利润贡献分开，识别基本盘、增量业务与尚未商业化业务。
2. 因果主线：供需、价格/销量/成本或目标行业适用变量如何传导到利润；区分周期修复和结构性增长。
3. 竞争与壁垒：产业链、竞合关系、技术/认证/客户黏性/规模，及壁垒失效条件。
4. 盈利质量：利润、扣非与现金流、营运资本、债务及一次性因素交叉检查，不机械年化。
5. 估值条件：在统一时点/币种/会计口径下讨论预期差，缺少比较基准则不作高低估判断。
6. 治理与资本配置：股东行为、质押、激励、关联交易、资本开支、合规及执行风险。
7. 时间线和情景：已披露与计划分开，定性假设→经营影响→可观察的验证/证伪条件。

## 不复制的内容

- 样本公司的业务结构、数据、市场地位、估值与预测。
- 主观评分、概率加权收益、目标价、买卖区间、止损和投资者适配建议。
- 样本中的算术和期间问题：第 7 页标注 7.15，但列出的加权算式为 7.075；第 10 页对半年报期间的文字表述不一致。模板只学习方法，不把样本视为已审计事实库。

## 真实性措施与限制

- 事实、推断、反证、跟踪变量单独展示，缺少资料可以为空，不强制凑财务指标或来源数量。
- 本轮 HTTP 资料和实际搜索工具返回的 URL 构成来源白名单；模型写出的 URL 不自动成为可信来源。
- 来源归属检查仅证明 URL 出现在本轮取数/检索记录中，不能证明网页中的每个陈述真实或与模型结论一致。提示词禁止用只有标题的公告/研报推导正文内容；仍需人工审阅重要结论。
- 结构化财务指标保持接口原始标签、期间、数值、单位和同比，当前报价只由行情接口写入；接口本身可能有延迟或错误。
- 未通过来源检查的内容移除，摘要和结论降级；没有行情就标未取得。研究失败不返回写死的公司样例报告。
- 情景不生成无依据的数字预测或概率；允许有来源的经营基数与明确列式的条件敏感性分析。不足以分析时明确缺口，不另发 AI 请求补造。数据可能不全，不能声称绝对消除模型错误。

## 成本与兼容性

- 用户已批准深度研究采用更强模型。深度研究默认 GPT-5.6 Sol，独立保存模型偏好；市场 Chat / 普通问答仍默认 GPT-5.6 Luna。后台允许模型范围、登录、每日限额和请求审计继续生效；Sol 不在允许范围时默认使用允许的 Luna 或首个允许模型。显式请求禁用模型仍拒绝。
- 仅用户主动触发。先 HTTP 读取多期三表、定期报告正文及资讯并复用 D1，再执行两个有上限的模型阶段：补证最多 6500 输出 Token、3–5 次联网，写作最多 14000 输出 Token且不联网。没有整篇自动重试或后台 AI 定时器；市场 chat 的独立预算不变。
- 通用框架单独维护并设置提示缓存键；不每次输入 15 页 PDF。
- 新字段随完整报告 JSON 保存；旧报告可继续读取，不自动重生成。新增章节在原报告页面显示并进入现有“另存 PDF”打印流程。
- 来源约束和空字段设计参考 OpenAI Structured Outputs 文档；结构化格式并不能保证事实正确。
