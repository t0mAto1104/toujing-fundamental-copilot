# 研究质量增强 v4

## 已落地的七项

1. 财务计算与写作分离：复用既有财报趋势、TTM、指标服务器计算；新增营业收入、归母净利润、经营现金流的原值、累计同比、单季、TTM、未季调单季环比计算账本。余额不作 TTM，非正基期不计算通常意义增长率，科目、人民币/元/合并/累计条件必须明确。
2. 数字—证据—计算绑定：每个账本结果保存公式、未四舍五入输入、期间、单位、币种、合并范围及来源；单季派生输入保留原始减法。报告可展开查看，PDF 导出自动展开。SHA-256 对抽取数据与正文片段留指纹，不是原 PDF 的文件签名，不等于所有正文数字和因果分析均经核验。
3. 阶段持久化和定向恢复：继续使用按用户/任务隔离的 D1 阶段快照与任务租约，新增阶段状态及写作结构校验。坏缓存只重做该阶段，不自动付费重试，也不删除成功的其他阶段。保留既有一小时检查点有效期；升级到 v4 不复用 v3 的写作检查点，已保存历史报告不受影响。
4. 缺口与冲突：同期间/科目的数值冲突、单位/范围未核实、缺少基期或取数失败单独记录，不任取某个值参与计算。文字来源的所有潜在语义冲突不能由此穷尽，仍需正文反证及人工核验。
5. 研究方法库＋检索：`lib/research-methods.ts` 为版本管理的内置方法片段，按问题、已核验行业和披露片段关键词排序，通用业务/现金方法保留。与公司事实分离，不存入样本公司的旧数字，不新增向量服务。新增方法目前由维护者审核后随代码更新，尚无用户上传资料/管理界面。
6. 历史研究差异：现有“我的报告”对比增加证据指纹、方法版本、同指标/期间/公式/单位的计算变化与缺口变化。旧报告明确未记录；跨上市证券禁止比较；风险或缺口不再列示不代表已消除。
7. 行业经营信号：银行、保险、证券、医药、半导体电子、软件互联网、周期制造资源、消费零售、地产建筑九类配置；无法匹配行业使用通用规则。仅检索本轮正式披露，保留页码和来源日期，标明原文命中或待补证。不假造 GPU 租金、台企月营收等外部新数据，不以代理指标替代公司实际经营数据。

## 成本和持久化边界

- 仍是既有 collect＋两个写作分段，无新增模型请求或定时 AI 消耗；方法/计算提示占用已有资料字符预算，输出上限不变。实际 Token 和质量变化需收费对照试验才可判断。
- 方法、完整计算和审计结果随完整报告写入现有 D1；复用原始财报和证据采集流程，不新增依赖或数据库表。
- 本轮使用模拟模型响应验证，没有真实模型账单。旧报告打开不重新研究；只有新生成报告有新增审计内容。
