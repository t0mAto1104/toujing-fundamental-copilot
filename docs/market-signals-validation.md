# 资金、题材与事件扩展验收（2026-09-07）

## 实施范围

- 新增左侧「资金与事件」：全市场龙虎榜、沪深港通日统计／北向季度持仓、解禁日历。
- 行情数据默认仍为大盘；新增「强势股与题材」。个股 K 线下提供资金流、龙虎榜、解禁、题材／公告，顶部增加板块归属分类。
- 市场总览增加精简的强势股／题材入口；行业比较增加板块资金页签；公司数据页复用同一套个股资金事件组件。
- 复用现有 HTTP、限流、D1 快照和自选表；没有新依赖、数据库迁移、API Key、OpenAI 调用或后台定时任务。只在可见页面按需刷新；公告展开后才请求，资金图表懒加载。

## 数据口径与来源核验

| 数据 | 采用来源与限制 |
| --- | --- |
| 强势股／题材 | 同花顺 getharden 热点样本，非全市场涨幅榜。成交额为万元，转为元；日期采用实际返回的交易日。来源编辑标签不冒充已证实的涨跌原因。 |
| 个股资金 | 东方财富 push2 分钟累计序列／push2his 日序列；分钟当天净额取末个有效值，不能把累计值逐分钟相加。保留主力、超大、大、中、小单及缺失值。 |
| 板块归属 | 东方财富 slist 混合列表，与真实类型目录按 BK 代码关联。分类以来源为准，不根据板块名称猜测。目录必须完整才缓存；复用完整行业缓存，分页沿用已成功的域名。 |
| 板块资金 | 东方财富行业／概念／地域，今日／5日／10日字段分别映射，50 条分页，显示源总数及 f124 数据时间。 |
| 龙虎榜 | 东方财富 RPT_DAILYBILLBOARD_DETAILS，限定股票类型，剔除可转债。默认最新披露日或个股近90日；指定日期严格查询。保留不同上榜原因的独立记录，席位按原因对齐，不重复相加。 |
| 解禁 | 东方财富 RPT_LIFT_STAGE。只用 CURRENT_FREE_SHARES 表示本次解禁股数，万元股单位转股；TOTAL_RATIO 转百分比。不把解禁后的流通股数或流通盘比例混用。 |
| 北向日统计 | 港交所官方每日沪股通／深股通成交额、笔数、ETF成交额、前十活跃证券。总额单位为百万元，前十金额为元；不推算或展示虚假的实时北向净流入。 |
| 北向持仓 | 港交所已披露季度末 A 股持仓，排除 ETF；日期取结果标题而非表单默认日期；证券代码取 A # 标识而非港交所内部编号。比例为来源原值，不再乘100。 |
| 公告 | 东方财富公告 API，核验证券关联和公告编号，展示真实标题、链接和发布时间。只对近期返回公告做日期附近筛选，不宣称完整因果归因。 |

北向披露制度参考：[上交所规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/global/hkexsc/c/c_20250613_10781806.shtml)、[港交所公告](https://www.hkex.com.hk/News/Market-Communications/2024/2404122news?sc_lang=en)。

## 容错与安全

- 明确空记录（东方财富 9201）与故障、超时分开处理。缺失数据不填零，不拼造行情。
- 18秒请求期限、3分钟共享失败冷却；失败保留并标注旧快照。默认最近披露与指定日期使用不同缓存键。
- 北向默认只因404／已知非交易日向前找披露；403、限流、传输及格式异常走旧缓存／错误，不能将更早数据悄悄标成最新。
- D1暂不可达时保留已有快照；过期内存重新查询共享D1，避免永久遮住其他实例刷新结果。
- 自选解禁筛选在服务端按已认证用户执行；匿名401，空自选返回空，不能意外退化成全市场。
- 保留既有行业AI比较面板的挂载状态，切换资金页签不丢失已生成结果；未改变研究 collect/write、模型默认值或额度逻辑。
