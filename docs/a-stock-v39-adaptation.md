# a-stock-data v3.9 HTTP 适配

参考上游 `24d61083c7e6337c2bcf69a081e7f63623f51520`。沿用 HTTP + D1 快照，不运行 Python 服务，不新增 Key、依赖、后台 AI 定时请求。本机安装的 skill 仍为 v3.8；本次是业务适配，不覆盖个人 skill 安装。

## 范围与入口

1. 来源验证：证券身份、日期、分页条数、重复记录、缺失值；异常不转换为零或成功空结果。
2. 腾讯 K 线三入口、失败冷却、分段日线历史；不允许原始价冒充复权价。公司历史百分位保留实际窗口和样本口径。
3. 行业研报来源切换（东财／新浪）与分页。行业代码可直查；机构或其他关键词仅匹配当前来源页，界面明确非全库搜索，不再把机构名扩展成整个行业。公司研报在东财失败或无结果时尝试新浪，仍受公司总时限控制。新浪仅详情链接，不编造 PDF、评级或覆盖承诺。
4. 舆情页沪深问答：深圳互动易、上海上证 e 互动；近 7/30 日，按提问日期，最多 10 页。北交所不支持。UID 目录单独共享缓存，不保留投资者个人资料。
5. 宏观页：事件日历、LPR、FR、FDR、中债收益率。研究写作仅复用新鲜 D1 缓存中的最新 LPR/曲线和公司事件，最多 2400 字符，不为补充信息启动额外模型请求，也不扩大已有输出预算。未缓存内容不进入报告。
6. 公司详情及市场信号页：90 天业绩预告、调研、增减持、回购、质押，可分页。质押为周频；回购按更新时间，不以预案金额冒充执行金额。
7. 财经资讯汇入华尔街见闻与央视新闻联播的近期经济政策信息，保留日期、链接并去重。央视只读取少量相关正文，不全量抓取视频。
8. 行情页选择 ETF 后显示官方份额：上交所所选日期及之前 7 个自然日；深交所仅最新完整快照。单位万份，差值不是资金净流入；没有前值不算变化。

## 运行边界

- 缓存、失败冷却和来源健康信息沿用 D1，不保证上游全天可用；失败显示错误或明确标记旧快照。
- 新浪请求启动间隔至少 6 秒，空列表最多再核验一次；限流为单运行实例，D1 共享结果。高并发跨地域需要另行部署分布式限流，当前不宣称全局限频。
- 冷启动的沪市问答目录查询、深市 ETF 全页拉取可能较慢，均有整体时限，不无限重试。
- API 支持不等于具备转售授权；公开站点继续遵守各来源的使用条款，不绕过验证码或访问限制。
- 本地真实取数已验证两市 ETF、沪市问答、两家新闻来源、新浪/东财研报、五类事件及五类宏观数据；外部接口时效和可达性仍需生产环境单独验证。
- 回归使用模拟模型响应，不产生 OpenAI 费用；公开发布需用户确认。
