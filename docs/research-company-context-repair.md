# 公司介绍、券商研究及缺口误报修复

日期：2026-09-26。针对用户提供的两份中信证券、农业银行、完美世界报告暴露的共用问题，不将任何样本财务数值硬编码进生产逻辑。

## 已实施

1. 公司指标接口复用研究链路的财务别名及已核验字段映射。“净利润”不替代“归母净利润”；同义科目数值冲突时拒绝任选其一。公司、资料、公开补证与阶段检查点版本更新，避免新任务复用旧解析。
2. 默认保持 7 模块，在“公司与业务”增加“公司简介与商业模式”“发展历程”两个字段。正式披露摘录优先保留简介和沿革；不足时进入已有联网补证预算，优先官网、正式公告并保留来源。历史事件不凭模型记忆填补。旧模板的原默认业务要求自动更新，用户自写要求和删除的模块不被覆盖；旧报告依然可读。
3. 券商使用经纪/财富管理、投行、资管、自营、净资本和资本风险规则，并区分监管与合并口径。不机械套用产能、存货周转、产品毛利率、CFO 净利润兑现率及通用企业现金结余估值。银行/券商经营原文在业务和财务两部分共享，降低跨章节资料不一致。
4. 区分实际资料缺口、取数失败、不适用与已被证据解决的缺口。取数失败保留在审计及来源模块的诊断记录，不直接断言公司未披露；真实缺口、来源冲突和复合缺口保留。相同缺口去重，跨行业/估值分类的同一缺口合并展示，避免重复列出。
5. 字段硬上限提供完整句余量，写作仍以较短完整表达为目标。新增识别数字截断后追加标点、部分明显残词和不完整引号；无法恢复时明确标记，不猜测补全，不自动重跑模型。

## 成本与安全边界

- 没有新增模型调用阶段、API Key、后台定时器或联网写作。原补证仍最多 2 次搜索，默认写作仍 2 个有界批次，模型输出 Token、并发、超时和费用上限不增加。
- 公司背景原文最多 2400 字符，银行/券商共享经营原文最多 3000 字符。实际输入与输出 Token 仍会随资料和模型变化；不能据此承诺单份费用不变。
- 继承登录、BYOK、预算锁、来源白名单、证券身份和提示词注入防护。来源在本轮目录中不代表每句事实都已人工审计。
- 只变更之后生成的报告，历史已保存报告和 PDF 不覆盖。旧用户自行选择的 3 模块模板不会被强行改成 7 模块。

## 验证

- 自动测试覆盖财务别名与冲突、公司背景及来源、券商识别负例、资料路由、跨章节经营证据、缺口分类与去重、残句、旧模板/旧报告兼容、费用与任务恢复。
- 375 项离线自动测试通过，TypeScript 通过。变更生产源码 lint 通过；部分旧测试文件仍存在历史 lint 告警，不宣称全仓库 lint 通过。
- 隔离浏览器测试通过：导航、模型选择、确认、失败保留模板、保存/刷新不再调用 AI、公司介绍/历程/来源、桌面与 375px 手机布局。4 页合成 PDF 已逐页查看，无新增文字裁切。
- 本轮未发起真实 OpenAI 请求、未重新生成四家真实公司的报告，未验证当次第三方接口可用率。测试用的合成情节不会进入用户数据。无法保证后续每个模型输出均无遗漏；仍需用用户主动生成的新报告复核实际效果。
