# 公司搜索修复验收（2026-09-03）

## 已复现的原因

- 东方财富 suggest 接口对维琪科技返回 `Code=920176`、`JYS=81`、`SecurityTypeName=京A`、`QuoteID=0.920176`。原白名单只允许北证A，不允许京A，导致名称和代码均被过滤。原市场转换也未处理京A。
- 用户确认“珠兔集团”指“珠免集团”。改动前后，真实接口均能以珠免集团、600185、格力地产查到同一证券；未添加错字、旧代码到证券的猜测映射。
- 原搜索会丢弃显式交易所：`SH000001` 错误返回平安银行。现在对公司搜索拒绝沪市指数及矛盾市场写法，不静默换成其他标的。
- 原接口将上游 HTTP 失败作为空结果，前端也丢弃错误。现在区分输入错误（400）、真实空结果（200）与上游异常（502），并在联想框显示错误；输入变化时清除上一查询候选项。

## 实现边界

沿用 a-stock-data 的 HTTP 取数、真实身份校验和东方财富限流规范；不新增 API Key、模型请求、定时器或数据库结构。保持非上市新三板、基金、指数、债券、期权的过滤；不因 Classify=NEEQ 而误排除已上市京A。

## 验证

- 修改前本地 `/api/listings`：维琪科技、920176 均返回 200 空列表；珠免集团、600185 正常；SH000001 错返平安银行。
- 修改后真实 HTTP：维琪科技、920176、BJ920176、920176.BJ 均返回北京证券交易所 920176；珠免集团、600185、格力地产均返回上海证券交易所 600185；SH000001 返回 400 指数提示；SZ000016 返回深圳证券交易所 *ST康佳A。
- 新增离线回归：京A/北证A 类型、沪深港股保留、非股票过滤、显式市场校验、旧代码不猜测、无关文本、HTTP/结构异常不冒充无匹配。测试使用真实字段结构，不执行网络或 AI 请求。
- 36 项回归测试、TypeScript 检查与生产构建通过。小米集团的港币、人民币双柜台及 ADR 搜索结果保留。

用户于验收后确认公开发布本次搜索修复；部署结果以 Sites 发布状态为准。
